Data Privacy Statement

Lumina Convert processes all your personal files (documents, scans, photos) locally inside your browser sandbox.

No backend uploads occur. When converting images to PDF, or extracting text using character recognition, the algorithms run offline utilizing local WebAssembly execution stacks.

AI image creation coordinates directly client-to-API with Pollinations AI. Prompts input are public parameters; do not include secure personal data in visual generation cues.
